# Redes sociales estilo dibujo a mano

Contenedor tipo hoja de cuaderno con bordes dibujados a mano e íconos pastel de redes que se mueven al pasar el mouse y muestran una etiqueta.

| Dato | Valor |
|---|---|
| Archivo original | `Boton 8 doodle container (carpeta Tool tips)` |
| Clases / selectores principales | `.doodle-container`, `.doodle-link`, `.link-spotify`, `.link-pinterest`, `.link-mail`, `.doodle-tooltip`, animación `child-wiggle` |
| Colores | Pasteles `#caffbf`, `#ffc4d9`; tinta `#1e1e24`. Fuente Patrick Hand. Requiere un filtro SVG con `id="pencil-texture"` |
| HTML | ⚠️ Pendiente: el archivo original solo traía el CSS. Agrega el HTML en `index.html`. |

## Archivos
- `style.css`: estilos del componente.
- `index.html`: marcado HTML (pendiente).

## Uso en un video (HyperFrames)
Copia el HTML y el CSS dentro de la composición y cambia los colores por los de `marca/colores/tokens.css`.
