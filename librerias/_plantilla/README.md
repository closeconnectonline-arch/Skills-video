# Nombre del componente

Descripción breve: qué es y qué hace al pasar el mouse o hacer clic.

| Dato | Valor |
|---|---|
| Origen | De dónde salió (sitio web, autor, archivo original) |
| Clases / selectores principales | `.mi-clase` |
| Colores | `#000000` |
| Fuentes | Ninguna / nombre de la fuente |
| HTML | Listo / Pendiente |

## Archivos
- `style.css`: estilos del componente.
- `index.html`: marcado HTML.

## Notas
Dependencias, variables que se pueden cambiar, advertencias.
