# Tres redes sociales con tooltip

Fila de íconos circulares blancos de redes sociales; al pasar el mouse cada uno toma el color de su red y muestra una etiqueta flotante.

| Dato | Valor |
|---|---|
| Archivo original | `Boton 5 tres redes` |
| Clases / selectores principales | `.wrapper`, `.icon`, `.tooltip`, `.facebook` (y demás redes) |
| Colores | Blanco; colores de cada red. Fuente Poppins |
| HTML | ✅ Reconstruido a partir del CSS (íconos de redes: Simple Icons, CC0; otros íconos: Bootstrap Icons, MIT) |

## Archivos
- `style.css`: estilos del componente.
- `index.html`: marcado HTML con una demo. Ábrelo en el navegador para verlo.

## Uso en un video (HyperFrames)
Copia el HTML y el CSS dentro de la composición y cambia los colores por los de `marca/colores/tokens.css`.
