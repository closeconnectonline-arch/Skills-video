# Cuatro redes sociales efecto vidrio

Íconos cuadrados redondeados con efecto vidrio (glassmorphism) y borde brillante del color de cada red: Spotify, Pinterest, Dribbble y Telegram.

| Dato | Valor |
|---|---|
| Archivo original | `Boton 6 cuatro redes sociales` |
| Clases / selectores principales | `.example-2`, `.icon-content`, atributo `data-social="spotify|pinterest|dribbble|telegram"`, animación `@keyframes premium` |
| Colores | Colores oficiales de cada red sobre vidrio translúcido |
| HTML | ⚠️ Pendiente: el archivo original solo traía el CSS. Agrega el HTML en `index.html`. |

## Archivos
- `style.css`: estilos del componente.
- `index.html`: marcado HTML (pendiente).

## Uso en un video (HyperFrames)
Copia el HTML y el CSS dentro de la composición y cambia los colores por los de `marca/colores/tokens.css`.
