# Selector de tres opciones

Lista vertical de opciones (radio buttons) con una barra luminosa amarilla que se desliza con rebote hacia la opción elegida. Soporta hasta 10 opciones cambiando `--total-radio`.

| Dato | Valor |
|---|---|
| Archivo original | `Boton 7 tres opciones` |
| Clases / selectores principales | `.radio-container`, `.glider-container`, `.glider` |
| Colores | Amarillo `#f7e479` (variable `--main-color`) |
| HTML | ⚠️ Pendiente: el archivo original solo traía el CSS. Agrega el HTML en `index.html`. |

## Archivos
- `style.css`: estilos del componente.
- `index.html`: marcado HTML (pendiente).

## Uso en un video (HyperFrames)
Copia el HTML y el CSS dentro de la composición y cambia los colores por los de `marca/colores/tokens.css`.
