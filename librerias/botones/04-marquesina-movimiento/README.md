# Botón marquesina en movimiento

Botón negro tipo píldora; al pasar el mouse el texto se convierte en una marquesina que se desplaza en bucle.

| Dato | Valor |
|---|---|
| Archivo original | `Boton 4 movimiento` |
| Clases / selectores principales | `.btn-23`, `.marquee`, animación `@keyframes marquee` |
| Colores | Negro `#000`, blanco |
| HTML | ⚠️ Pendiente: el archivo original solo traía el CSS. Agrega el HTML en `index.html`. |

## Archivos
- `style.css`: estilos del componente.
- `index.html`: marcado HTML (pendiente).

## Uso en un video (HyperFrames)
Copia el HTML y el CSS dentro de la composición y cambia los colores por los de `marca/colores/tokens.css`.
