# Botón espaciado hover

Botón blanco tipo píldora. Al pasar el mouse se vuelve morado, separa las letras y proyecta sombra; al hacer clic baja como si se presionara.

| Dato | Valor |
|---|---|
| Archivo original | `Boton 1` |
| Clases / selectores principales | `button` (estilo global: afecta a **todos** los botones de la página; conviene cambiarlo a una clase) |
| Colores | Blanco, morado `hsl(261 80% 48%)` |
| HTML | ✅ Reconstruido a partir del CSS (íconos de redes: Simple Icons, CC0; otros íconos: Bootstrap Icons, MIT) |

## Archivos
- `style.css`: estilos del componente.
- `index.html`: marcado HTML con una demo. Ábrelo en el navegador para verlo.

## Uso en un video (HyperFrames)
Copia el HTML y el CSS dentro de la composición y cambia los colores por los de `marca/colores/tokens.css`.
