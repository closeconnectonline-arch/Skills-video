# Botón marcador con ícono

Botón negro con un círculo de ícono degradado rosa-morado que se expande y tapa el texto al pasar el mouse.

| Dato | Valor |
|---|---|
| Archivo original | `Boton 2` |
| Clases / selectores principales | `.bookmarkBtn`, `.IconContainer`, `.icon`, `.text` |
| Colores | Negro `rgb(12,12,12)`, degradado `rgb(255,136,255)` → `rgb(172,70,255)` |
| HTML | ⚠️ Pendiente: el archivo original solo traía el CSS. Agrega el HTML en `index.html`. |

## Archivos
- `style.css`: estilos del componente.
- `index.html`: marcado HTML (pendiente).

## Uso en un video (HyperFrames)
Copia el HTML y el CSS dentro de la composición y cambia los colores por los de `marca/colores/tokens.css`.
